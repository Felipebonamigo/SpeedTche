  return { state, track, telemetry, feel, step };
}

   **`createPlaylog`:**
   - lê `sanitizePlaylog(deps.read(PLAYLOG_KEY))` uma vez;
   - **antes de `sessionStart()`**, `input`, `raceStarted`, `raceEnded` e `answerSurvey` não fazem nada, e `askSurveyBefore` devolve `false`;
   - `sessionStart()`:
     - cria `{ id: nextSession++, start: now, last: now, version: deps.version, races: 0, completed: 0, funnel: null }`;
     - abre o funil (início = agora, entradas = 0) e zera a marca "já perguntou nesta sessão";
     - grava;
