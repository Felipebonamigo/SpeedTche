### 1. Objetivo

1. **Até 3 estrelas por corrida de copa** (Expedição e copa avulsa): ★1 **classificar** (a regra do `applyRaceResult`), ★2 **vencer o rival da copa** (o humano termina à frente dele), ★3 **o objetivo da pista**.
2. **Objetivo da pista**: um de 6, escolhido por `hashString(trackId)` (puro, estável, o mesmo para todos): sem batida · volta perfeita · 20 s no vácuo · sem box · do último ao top 3 · nitro na bandeira. Aparece **antes da largada** (detalhe da copa, garagem da Expedição) e **no Pagamento**.
3. **Troféu por copa e por perfil** (bronze, prata, ouro) e o contador **"x/327"** (109 pistas × 3).
4. **Placar persistente por rival e por perfil** ("Zé Turbo 7 × 5 você"); as falas de apresentação **escolhidas pelo placar** e o **balão da corrida** citando-o. Sem palavrão.
5. **Retratos** dos 20 pilotos (os 12 rivais de copa estão entre eles) com 3 expressões (provoca, venceu, perdeu), SVG procedural provisório (`src/ui/art/portraits.ts`), no cartão do rival, no balão e no Pagamento.

### 4. Contrato

#### 4.1 `src/game/stars.ts` (puro; sem DOM)

```ts
export const STAR_QUALIFY = 1, STAR_RIVAL = 2, STAR_GOAL = 4;           // bits do mapa por pista
export type GoalId = 'clean' | 'perfectLap' | 'draft20' | 'noPit' | 'comeback' | 'nitroFinish';
export const GOALS: readonly GoalId[];                                   // ordem fixa = o hash não muda ao reordenar texto
export function goalFor(trackId: string): GoalId;                        // GOALS[hashString(trackId) % 6]
export function goalMet(goal: GoalId, seat: number, finished: boolean, position: number, tel: RaceTelemetry): boolean;
export interface RivalScore { you: number; rival: number }
export interface StarProfile { name: string; tracks: Record<string, number>; rivals: Record<string, RivalScore> }
export interface StarsLast { name: string; trackId: string; got: number; was: number; goal: GoalId; rival: string | null; duel: 'win' | 'lose' | null }
export interface StarsData { profiles: StarProfile[]; last: StarsLast[] }
export const STARS_TOTAL = 327;                                          // = 3 × corridas de copa (teste confere com CUPS)
export function settleStars(save: StarsData, input): StarsLast[];        // grava e devolve o que mudou, por humano local
export function starCount(p: StarProfile | undefined): number;           // 0..327
export function cupStars(p, cup: CupDef): { got: number; max: number };
export type Trophy = 'none' | 'bronze' | 'silver' | 'gold';
export function trophyFor(got: number, max: number): Trophy;
export function scoreOf(data: StarsData, name: string, rivalKey: string): RivalScore;
export type ScoreState = 'none' | 'rival' | 'you' | 'even';
export function scoreState(s: RivalScore): ScoreState;
export function sanitizeStars(raw: unknown): StarsData;
```

Regras de `settleStars` (só `cup`/`career`; por humano **local**, pelo `profileKey` do nome):
- ★1 = co-op: `champ.lastVerdict === 'qualified'`; senão `posição ≤ QUALIFY_POSITION`. Sem copa (`champ` nulo): sem estrela.
- ★2 = existe o rival no `results` (seat < 0, nome = `config.rival`) e `posição do humano < posição do rival`. O placar soma 1 para quem ficou à frente (empate de posição não existe).
- ★3 = `goalMet(goalFor(trackId), …)` — o humano **terminou** a corrida. `clean`: `collisions === 0 && crashes === 0`; `perfectLap`: `tel.perfectLap.has(seat)`; `draft20`: `draftTicks ≥ 20·TICK_RATE`; `noPit`: `!tel.pitted.has(seat)`; `comeback`: `lastAfterFirstLap && posição ≤ 3`; `nitroFinish`: `nitroAtFinish`.
- O mapa por pista é **OU de bits** (a melhor corrida de cada estrela; nunca diminui). O contador conta bits.
- `last` guarda **só a última corrida** (`was`/`got` para o Pagamento mostrar "nova"); é substituído a cada corrida (como `career.lastReport`).
- Idempotente pelo `r.outcome` do `settleRace` (já é: só roda uma vez por corrida).

#### 4.2 Save: campo aditivo `stars` (sem versão de formato; o saneador é a migração, como `seatLooks`/`sessionStart`)

```json
"stars": {
  "profiles": [ { "name": "Ana", "tracks": { "copacabana": 7, "paraty": 3 }, "rivals": { "ze_turbo": { "you": 5, "rival": 7 } } } ],
  "last": [ { "name": "Ana", "trackId": "paraty", "got": 3, "was": 1, "goal": "noPit", "rival": "Zé Turbo", "duel": "win" } ]
}
```

**`sanitizeStars`** (nunca lança): `profiles` só de objeto, no máximo `MAX_PROFILES` (32), nome limpo (`cleanName`, 12) e **sem repetir `profileKey`** (a primeira vale); `tracks` só com id que existe em `TRACKS` e valor inteiro, `& 7`, descartando 0; `rivals` só com chave de rival de `CUP_RIVALS` e contagens inteiras em `0..99999`, descartando 0×0; `last` no máximo 4, com `goal` conhecido, `got`/`was` `& 7`, `duel` `win|lose|null`; qualquer outro tipo → vazio. Atalho deliberado: perfil que sai pelo limite leva as estrelas dele (o total das estatísticas também limita em 32; a S3 troca por perfil escolhido de uma lista).

**Migração:**
| Entrada | Resultado |
|---|---|
| Save **sem** `stars` (qualquer save de até a 0.1.3) | abre intacto; `stars` = `{profiles: [], last: []}`; todo o resto **igual** (teste com fixture literal) |
| `stars` com lixo (string, array, nulos, id de pista que não existe) | cai no vazio / descarta só o item ruim |
| Save novo aberto na **0.1.3** | abre sem erro (o saneador dela é por lista branca e **ignora** o campo); **a próxima gravação da 0.1.3 descarta `stars`** — mesma limitação que a 0.1.2 teve com `sessionStart`. Não há como o código antigo preservar campo que não conhece; o aviso vai nas notas do release |

#### 4.3 Troféu (valores recomendados; constantes em `stars.ts`)

`got/max` da copa do perfil (max = 3 × corridas): **bronze** ≥ 1/3, **prata** ≥ 2/3, **ouro** = todas (`got === max`). Menos que 1/3: sem troféu. Derivado, **não gravado** (muda de valor sem migrar).

#### 4.4 Placar e falas

- `rivals`: `{you, rival}` por perfil e rival (chave `driverKey`). **Só entra corrida de copa/Expedição com o rival no grid**; por humano local.
- `scoreState`: `none` (0×0) · `rival` (rival ≥ 2 à frente) · `you` (você ≥ 2 à frente) · `even` (o resto).
- `rivalLineFor(rival, kind, score?)`: com `intro` e placar ≠ `none`, a fala vem de `rivals.score.<personalidade>.<estado>` (12 frases por idioma, com `{r}` e `{y}`); sem placar, o texto de hoje. As falas pós-corrida seguem as de hoje (já citam o resultado).
- **Balão da corrida** (`rivalTalkText` e a resposta à buzina): com placar ≠ `none`, `"{nome}: " + frase do placar`; sem, a de hoje. Todas as frases novas passam por um teste que reprova palavrão (lista curta, PT e EN) e comprimento ≤ 70 caracteres.
- Linha do cartão: `rivals.scoreLine` = `"{name} {r} × {y} você"` / `"{name} {r} × {y} you"`.

#### 4.5 Retratos (`src/ui/art/portraits.ts`)

`portrait(name: string, face: 'taunt'|'win'|'lose', opts?: {size?: number}): SVGSVGElement` — SVG procedural **determinístico** por `hashString(name)`: tom de pele (6), cabelo (cor e forma, 6), capacete (cor), acessório (nenhum, óculos, boné, bigode, faixa). Cada expressão muda sobrancelha e boca (e olhos fechados no `win`). **Distintos:** os 20 pilotos geram 20 marcações diferentes e cada um tem 3 expressões diferentes (teste). Nome desconhecido (humano) gera o mesmo tipo de rosto. `aria-hidden` (o nome já está no texto) e `data-face`. Sem imagem externa. A trilha A troca o arquivo inteiro depois (mesma assinatura).

#### 4.6 Telas

- **Detalhe da copa** (`select.ts`): o bloco do rival ganha retrato + placar; cada corrida mostra as estrelas do perfil (3 ícones) e o objetivo da pista (texto curto); o chip da copa mostra o troféu; a barra de etapas ganha "★ x/327".
- **Garagem da Expedição** (`garageRivalBlock`): objetivo da próxima corrida + placar.
- **Resultado/Classificação** (`rivalCard`): retrato (`win`/`lose` pelo duelo, `taunt` na apresentação) e a linha do placar.
- **Pagamento** (`payout.ts`): faixa **Estrelas**: 3 estrelas (acesas/apagadas, "nova" marcada), o objetivo e se foi cumprido, o retrato do rival com a expressão do duelo. `reduceEffects`: sem brilho/animação (só estado). Navegação inalterada (mesmo foco, mesmos botões).
- **Teclado/controle**: nenhum controle novo; tudo é leitura dentro de itens já focáveis. Foco e `data-post-*` do Pagamento não mudam.
- **i18n**: namespace novo `stars` (`src/stars/strings.ts`) + frases em `src/rivals/strings.ts`, PT e EN (o `tests/i18n.test.ts` confere).
